# কতোয়াল পুর কমিউনিস্ট পার্টি (KCP) ✊☕

**দুনিয়ার আড্ডাবাজ এক হও!** — একটি সম্পূর্ণ হাস্যরসাত্মক সংগঠনের অফিসিয়াল ওয়েবসাইট।
হেড অফিস: পিছের মুখ, বৃহত্তর কতোয়ালপুর · পার্টি অফিস: সুফান বিকাশ ঘর

## যা যা আছে

- অফিসিয়াল ঘোষণাপত্র (স্মারক নং ককপা/২৬/০১) — নামে ক্লিক করলে নেতার প্রোফাইলে যায়, মূল কপির ছবিও দেখা যায়
- ১২ জনের কেন্দ্রীয় আহ্বায়ক কমিটি, দল অনুযায়ী ফিল্টারসহ

- ঘুরতে থাকা স্লোগান আর ব্রেকিং নিউজ টিকার
- পরবর্তী সভার লাইভ কাউন্টডাউন (প্রতি শুক্রবার বিকাল ৫টা)
- ক্লিক করলে উল্টে যায় এমন ইশতেহার কার্ড
- নেতাদের ছবিতে ক্লিক করলে তাঁদের বাণী
- বিপ্লব মিটার (কমরেডরা মাঝে মাঝে ঘুমিয়ে পড়েন)
- স্লোগান মেশিন (কপি করে ফেসবুকে দেওয়া যায়)
- "আপনি কতটা খাঁটি কমরেড?" কুইজ
- সদস্য কার্ড বানানো ও PNG ডাউনলোড
- পালিয়ে যাওয়া চাঁদার বোতাম
- আড্ডা জোন (ট্যাবে ৬টা খেলা):
  - "আজকের চায়ের বিল কে দেবে?" ঘূর্ণি চাকা
  - চা ঢালো চ্যালেঞ্জ (চেপে ধরে রাখার খেলা)
  - ঘুমন্ত কমরেড জাগাও (উঁকি দিলেই ট্যাপ)
  - কে বলেছে? (বাণী দেখে কমরেড চেনা)
  - সিঙ্গারা ধরো (ঝুড়ি টেনে সিঙ্গারা ধরা, বিল এড়ানো)
  - আড্ডায় না আসার অজুহাত মেশিন
- "সভায় আনো!" (`sim/`) — আলাদা পেজে "পংকি ভাইয়ের সিএনজি" খেলা: কতোয়ালপুরের আসল ম্যাপে (OpenStreetMap) ঘুমন্ত কমরেডদের জাগিয়ে সুফান বিকাশ ঘরে আনা। মাঝপথে লোডশেডিং আর ঝুম বৃষ্টি, ভোটের পোস্টার আর মিছিল ("এমরান ভাই এমরান ভাই!"), রাস্তায় "সামনে সাম ভাই" (গায়ে সিএনজি তুললে গেম ওভার), হ্যাটট্রিক, মাইজপাড়া-পশ্চিমপাড়ার নাম, ড্রোন থেকে দেখার মতো ২.৫ডি বাড়িঘর (দেয়াল, জানালা, বিকালের লম্বা ছায়া, লোডশেডিংয়ে আইপিএসওয়ালা বাড়িতে আলো), আসল জায়গাগুলো আসল ঠিকানায়: পুদিনা-সবুজ দোতলা সুফান বিকাশ ঘর (নিচে দোকান, বারান্দায় পার্টির ব্যানার, রাস্তার পশ্চিম পাশে, পাশে আধা-বানানো ইটের বাড়ি), সামনে টিনের চালার "ভাইয়ার দোকান", ফিরোজা দেয়াল ও লাল-নীল গেটের "সুফান প্যালেস" (ম্যাপে নেই বলে হাতে বসানো), আর তিন রাস্তার মোড়ে ক্রিম দেয়াল আর নীল গেটের পাশে চা-চিপসের "রিয়েল মামুর দোকান"। খেলার আগে চালক বাছাই: পংকি ভাই (স্পিড বেশি, কিন্তু এক্সিডেন্টের ভয়ও বেশি) নাকি নেতা মুহন ভাই (সাবধানী, কিন্তু মিছিল দেখলে থেমে স্লোগান দেন)। ভাইয়ার দোকানে থামলে চা, রিয়েল মামুর দোকানে চিপস; কেউ অজুহাত দিলে ঠিক জবাব বাছতে হয় (চা, চিপস, নাকি "এমরান ভাই আসতেছেন!")। ফোনে ◀ ▶ আর গ্যাস-ব্রেকের বোতাম দিয়ে চালানো যায়। শেষে মজার পুরস্কার। প্রতি কমরেডে ভাড়া (৳), গরু-দেয়ালে জরিমানা, আর জমানো টাকায় "দোকান" থেকে নতুন হর্ন, সিএনজির রং আর আপগ্রেড (চতুর্থ সিট, নতুন ইঞ্জিন, LED লাইট, গরু-বাম্পার, ছাতা) কেনা যায়, ব্রাউজারেই সেভ থাকে। মিম সাউন্ডগুলো কোডে বানানো (কোনো কপিরাইট ক্লিপ নেই)। হর্নের শব্দ (`sim/horn.mp3`) উইকিমিডিয়া কমন্সের "Car Horn.wav" (CC0) থেকে কেটে বানানো
- "সভায় আনো! ৩ডি" (`sim3d/`) — একই খেলা পুরো ৩ডিতে (Three.js): একই আসল ম্যাপে ৩ডি বাড়িঘর, গাছ, নারকেল গাছ, মসজিদ, ঢাকার আসল সিএনজির মতো করে বানানো ৩ডি সিএনজি (জালের দরজা, কালো ছাদ, পিছনে লেখা "পংক পরিবহন"), আসল সুফান বিকাশ ঘরের মতো দোতলা পার্টি অফিস (পুদিনা-সবুজ দেয়াল, নিচে দোকান, বারান্দায় পার্টির ব্যানার), সামনে মরচে-ধরা টিনের "ভাইয়ার দোকান", "সুফান প্যালেস" আর নীল গেটের পাশে "রিয়েল মামুর দোকান", চালক বাছাই (পংকি ভাই বা নেতা মুহন ভাই), দোকানে থেমে চা-চিপস আর কমরেডদের অজুহাতের জবাব, তিন রকম ক্যামেরা (C চাপলে বদলায়), ফোনে ◀ ▶ ঘোরানোর আর গ্যাস-ব্রেকের বোতাম (জয়স্টিকও আছে)। ৩ডিতেও "দোকান" আছে: পংকি ভাইয়ের গ্যারেজে সিএনজি ঘুরিয়ে দেখে হর্ন, রং আর আপগ্রেড কেনা যায় (রং কেনার আগে দেখে নেওয়া যায়); টাকা আর জিনিস ২ডি খেলার সাথে একই পকেটে। ব্যাকগ্রাউন্ড মিউজিক (`sim3d/music.mp3`): "Happy Adventure (Loop)", TinyWorlds, OpenGameArt.org থেকে (CC0)
- স্লোগান ও অজুহাত হোয়াটসঅ্যাপ/ফোনের শেয়ার মেনুতে পাঠানো যায়
- ফোনের জন্য: নিচে মেনু বার, কমিটি ডানে-বামে সোয়াইপ, ট্যাপ করলে হালকা কাঁপুনি (অ্যান্ড্রয়েডে)
- গোপন মজা: প্রতীকে পরপর ৫ বার ট্যাপ করুন

## GitHub Pages-এ ফ্রি ডিপ্লয়

১. github.com-এ নতুন **public** repository বানান, যেমন `kcp`।

২. এই ফোল্ডার থেকে টার্মিনালে:

```bash
git init
git add .
git commit -m "KCP website"
git branch -M main
git remote add origin https://github.com/<your-username>/kcp.git
git push -u origin main
```

৩. GitHub-এ repository → **Settings** → **Pages** → *Source*: **Deploy from a branch** → Branch: **main**, folder: **/ (root)** → **Save**।

৪. ১-২ মিনিট পর সাইট চালু হবে এখানে: `https://<your-username>.github.io/kcp/`

নিজস্ব ডোমেইন: সাইটটি এখন **https://joinkcp.com** ঠিকানায় চলে (Cloudflare-এ কেনা)। Cloudflare DNS-এ `@`-এর জন্য GitHub-এর ৪টা A রেকর্ড (185.199.108–111.153) আর `www` → `imamachowdhury.github.io` CNAME রেকর্ড আছে, সবগুলো "DNS only" (ধূসর মেঘ)। GitHub-এ Settings → Pages → Custom domain-এ `joinkcp.com` দেওয়া আছে।

পরে কিছু বদলালে প্রথমে `index.html`-এ `style.css?v=` আর `script.js?v=` নম্বর এক বাড়িয়ে দিন (যেমন ৮ থেকে ৯), যাতে সবার ব্রাউজারে পুরোনো ফাইল না থাকে। তারপর:

```bash
git add . && git commit -m "update" && git push
```
