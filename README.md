# কতোয়াল পুর কমিউনিস্ট পার্টি (KCP) ✊☕

**দুনিয়ার আড্ডাবাজ এক হও!** — একটি সম্পূর্ণ হাস্যরসাত্মক সংগঠনের অফিসিয়াল ওয়েবসাইট।
হেড অফিস: পিছের মুখ, বৃহত্তর কতোয়ালপুর · পার্টি অফিস: সুফান বিকাশ ঘর

## যা যা আছে

- অফিসিয়াল ঘোষণাপত্র (স্মারক নং ককপা/২৬/০১) — নামে ক্লিক করলে নেতার প্রোফাইলে যায়, মূল কপির ছবিও দেখা যায়
- ১২ জনের কেন্দ্রীয় আহ্বায়ক কমিটি, দল অনুযায়ী ফিল্টারসহ

- ঘুরতে থাকা স্লোগান আর ব্রেকিং নিউজ টিকার
- পরবর্তী সভার লাইভ কাউন্টডাউন (প্রতি শুক্রবার বিকাল ৫টা)
- ক্লিক করলে উল্টে যায় এমন ইশতেহার কার্ড
- নেতাদের ছবিতে ক্লিক করলে তাঁদের বাণী
- বিপ্লব মিটার (কমরেডরা মাঝে মাঝে ঘুমিয়ে পড়েন)
- স্লোগান মেশিন (কপি করে ফেসবুকে দেওয়া যায়)
- "আপনি কতটা খাঁটি কমরেড?" কুইজ
- সদস্য কার্ড বানানো ও PNG ডাউনলোড
- পালিয়ে যাওয়া চাঁদার বোতাম

## ফাইল

| ফাইল | কাজ |
|---|---|
| `index.html` | পুরো পেজ |
| `style.css` | ডিজাইন |
| `script.js` | সব ইন্টারঅ্যাকশন। কমিটি (`COMMITTEE`), স্লোগান, খবর, ইশতেহার — সব এই ফাইলের একদম উপরে, সহজেই বদলানো যায় |
| `assets/` | প্রতীক (`emblem.jpg`), ব্যানার, সিল, মূল ঘোষণাপত্র ও favicon |

কোনো বিল্ড বা ইনস্টল লাগে না।

## GitHub Pages-এ ফ্রি ডিপ্লয়

১. github.com-এ নতুন **public** repository বানান, যেমন `kcp`।

২. এই ফোল্ডার থেকে টার্মিনালে:

```bash
git init
git add .
git commit -m "KCP website"
git branch -M main
git remote add origin https://github.com/<your-username>/kcp.git
git push -u origin main
```

৩. GitHub-এ repository → **Settings** → **Pages** → *Source*: **Deploy from a branch** → Branch: **main**, folder: **/ (root)** → **Save**।

৪. ১-২ মিনিট পর সাইট চালু হবে এখানে: `https://<your-username>.github.io/kcp/`

পরে কিছু বদলালে শুধু:

```bash
git add . && git commit -m "update" && git push
```
